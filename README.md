# S.O.L.A.R

**Smart Omni-capable Learning And Reasoning.** Snip anything on your screen and get the answer: homework, code, charts, words in another language. It checks its own math, draws figures in 2D and 3D, answers in your language and can work offline.

This repository only holds the downloads. Website: https://solar-44.web.app

## Download (Windows 10 / 11)

**[Download SOLAR-Setup.exe](https://github.com/Wraith0010/S.O.L.A.R/releases/latest/download/SOLAR-Setup.exe)**

1. Run the installer and press Install.
2. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
3. Sign in, then press **Alt+Q** and drag a box around anything.
